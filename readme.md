# 🤖 JIBA – A KTU Buddy

An AI-powered academic assistant built to help KTU students with 
syllabus-related queries using the OpenAI API.

## 🚀 Features
- 📚 Covers 100+ KTU syllabus topics across multiple subjects
- ⚡ Average response time under 2 seconds
- 💬 Interactive and responsive chatbot interface
- 🎯 Optimized prompt engineering for accurate academic answers
- 📉 Reduced inaccurate responses by approximately 35%

## 🛠️ Technologies Used
- **Frontend:** Streamlit
- **Backend:** Python, Flask
- **AI:** OpenAI API
- **Styling:** HTML, CSS

## ⚙️ How to Run

1. Clone the repository
   git clone https://github.com/Basi467/jiba-ktu-buddy.git

2. Navigate to the project folder
   cd jiba-ktu-buddy

3. Install dependencies
   pip install -r requirements.txt

4. Add your OpenAI API key
   Create a .env file and add:
   OPENAI_API_KEY=your_api_key_here

5. Run the application
   streamlit run app.py

## ⚠️ Note
You need your own OpenAI API key to run this project.
Get one at platform.openai.com
